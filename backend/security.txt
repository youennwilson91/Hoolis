## 🔒 SÉCURITÉ

### **✅ Protections Activées**

#### **1. Authentification & Sessions**
- JWT avec rotation automatique (1h de validité)
- Cookies sécurisés (HttpOnly, Secure)
- Protection CSRF activée

#### **2. Protection des Données**
- SECRET_KEY sécurisée (64 caractères)
- Mots de passe hashés avec PBKDF2
- Variables d'environnement (pas de secrets en dur)

#### **3. Protection Réseau**
- CORS configuré par environnement
- Rate limiting (100 req/h anonymes, 1000 req/h utilisateurs)
- En-têtes de sécurité (XSS, CSRF, Clickjacking)

#### **4. Monitoring**
- Logs de sécurité dans `backend/logs/security.log`
- Audit automatique avec `security_check.py`

#### **5. Dépendances de Sécurité Installées ✅**
- `django-axes` - Protection contre les attaques par force brute
- `django-ratelimit` - Limitation du taux de requêtes
- `django-csp` - Content Security Policy
- `bandit` - Analyse statique de sécurité
- `safety` - Vérification des vulnérabilités
- `cryptography` - Cryptographie moderne
- `whitenoise` - Servir les fichiers statiques sécurisés

## 🌐 FRONTEND/BACKEND

### **Configuration CORS**
```python
# Développement (DEBUG=True)
CORS_ALLOWED_ORIGINS = [
    "http://localhost:5173",    # ✅ Votre frontend Vite
    "http://127.0.0.1:5173",   # ✅ Alternative
]

# Production (DEBUG=False)  
CORS_ALLOWED_ORIGINS = [
    "https://votre-domaine.com",  # À configurer
]
```

### **Configuration Frontend**
```javascript
// frontend/.env (à créer)
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_API_URL=http://127.0.0.1:8000/api

// Dans votre code React
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8000';

const fetchData = async () => {
  const response = await fetch(`${API_BASE_URL}/api/endpoint/`, {
    method: 'GET',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`, // Si authentifié
    },
    credentials: 'include', // Important pour les cookies
  });
  return response.json();
};
```

### **Endpoints API Disponibles**
- `http://127.0.0.1:8000/api/` - API principale
- `http://127.0.0.1:8000/api/auth/` - Authentification
- `http://127.0.0.1:8000/admin/` - Interface admin

## 🚀 DÉPLOIEMENT

### **🐳 Option 1 : Docker (Recommandé)**

#### **Étape 1 : Préparer la production**
```bash
# Copier le template de production
cp env.production .env

# Éditer avec vos vraies valeurs
nano .env
```

#### **Étape 2 : Variables de production obligatoires**
```bash
# Dans .env
DJANGO_SECRET_KEY=GENERER_UNE_NOUVELLE_CLE_SECRETE_PRODUCTION
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=votre-domaine.com,www.votre-domaine.com
DB_PASSWORD=MotDePasseProductionTresSecurise456!
ADMIN_EMAIL=admin@votre-domaine.com
```

#### **Étape 3 : Déployer**
```bash
# Construire et lancer
docker-compose -f docker-compose.prod.yml up -d

# Vérifier les logs
docker-compose -f docker-compose.prod.yml logs -f web
```

### **🖥️ Option 2 : Serveur Linux**

#### **Étape 1 : Variables système**
```bash
# Créer le fichier .env sur le serveur
sudo nano /var/www/hoolis/.env

# Sécuriser le fichier
sudo chmod 600 /var/www/hoolis/.env
sudo chown www-data:www-data /var/www/hoolis/.env
```

#### **Étape 2 : Service systemd**
```bash
# Créer le service
sudo nano /etc/systemd/system/hoolis.service
```

```ini
[Unit]
Description=Hoolis Django Application
After=network.target

[Service]
Type=exec
User=www-data
Group=www-data
WorkingDirectory=/var/www/hoolis/backend
EnvironmentFile=/var/www/hoolis/.env
ExecStart=/var/www/hoolis/venv/bin/gunicorn --bind 127.0.0.1:8000 mysite.wsgi:application
Restart=always

[Install]
WantedBy=multi-user.target
```

#### **Étape 3 : Activer**
```bash
sudo systemctl daemon-reload
sudo systemctl enable hoolis
sudo systemctl start hoolis
```

### **☁️ Option 3 : Hébergeurs Cloud**

#### **Heroku**
```bash
heroku config:set DJANGO_SECRET_KEY="votre-cle-production"
heroku config:set DJANGO_DEBUG="False"
heroku config:set DJANGO_ALLOWED_HOSTS="votre-app.herokuapp.com"
```

#### **DigitalOcean / AWS / Azure**
- Utiliser l'interface web pour configurer les variables d'environnement
- Copier les valeurs depuis `env.production`

## 🔧 MAINTENANCE

### **📊 Monitoring Quotidien**
```bash
# Vérifier la sécurité
cd backend
python security_check.py

# Surveiller les logs
tail -f logs/security.log

# Vérifier les ressources
htop  # CPU/RAM
```

### **🔄 Mise à Jour Sécurisée**
```bash
# 1. Sauvegarder
sudo cp -r /var/www/hoolis /var/backups/hoolis-$(date +%Y%m%d)

# 2. Mettre à jour
git pull origin main

# 3. Tester la sécurité
python security_check.py

# 4. Redémarrer
sudo systemctl restart hoolis
```

### **🆘 Dépannage**

#### **Frontend ne peut pas accéder au backend**
```bash
# Vérifier le mode DEBUG
echo $DJANGO_DEBUG

# Activer pour développement
$env:DJANGO_DEBUG="True"  # Windows
export DJANGO_DEBUG="True"  # Linux

# Tester la connectivité
python test_cors.py
```

#### **Erreurs de permissions**
```bash
sudo chown -R www-data:www-data /var/www/hoolis
sudo chmod -R 755 /var/www/hoolis
sudo chmod 600 /var/www/hoolis/.env
```

#### **Variables d'environnement non reconnues**
```bash
# Vérifier les variables
env | grep DJANGO

# Recharger la configuration
sudo systemctl restart hoolis
```
